# Homebrew Tap For PDF Laser

This tap publishes the macOS release of [PDF Laser](https://github.com/chkwon/PDFLaser).

## Install

```sh
brew install --cask chkwon/tap/pdflaser
```

Or tap the repository first:

```sh
brew tap chkwon/tap
brew install --cask pdflaser
```

## Upgrade

```sh
brew update
brew upgrade --cask pdflaser
```

## Uninstall

```sh
brew uninstall --cask pdflaser
```
